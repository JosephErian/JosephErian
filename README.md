### About Me

I'm a full stack software developer with 3+ years of professional experience building web, mobile, and desktop applications end-to-end — from database design to native app packaging. I enjoy picking the right tool for the job rather than sticking to one stack, which is why my work spans:

- **Web:** MERN stack, Next.js, Vite + React, Angular
- **Mobile:** React Native with Expo
- **Desktop:** Electron (with React and with .NET)
- **Backend:** .NET, Node.js
- **DevOps/Cloud:** AWS, Azure

I care about shipping software that's reliable and maintainable, not just functional — clear architecture, sensible tooling choices, and documentation that respects the next person's time (including future me).
